# Copyleft Licenses

Match exact SPDX expressions, including only/or-later and WITH exceptions.
Do not treat a family name as a complete license expression.

- GPL: distinguish private use from conveying covered works; assess source and
  object-code obligations for the version and delivery method. Mere aggregation
  and a combined work are different questions.
- LGPL: application/library boundaries, library modifications, notices,
  relinking and installation requirements matter. Version 3 section 4(d) permits
  alternative compliance mechanisms; dynamic linking is not the only possibility.
- AGPL: check ordinary distribution rules separately from the additional remote
  interaction rule for modified versions. No global “only modified SaaS matters”
  shortcut, and no automatic requirement to disclose unrelated server software.
- MPL-2.0: covered files retain their terms; secondary-license combinations are
  conditional, including the Incompatible With Secondary Licenses designation.

Avoid project-name examples unless verified at the requested version. In
particular, WordPress states GPLv2 or later, not simply GPLv3.
