# NOTICE and Attribution

A NOTICE file is not a substitute for LICENSE or all dependency license texts.
For Apache-2.0, section 4(d) addresses readable attribution notices supplied in an
upstream NOTICE when distributing derivative works, excluding notices that do not
pertain. Do not claim every Apache project must invent a new NOTICE file.

Inspect actual shipped dependencies, versions and notices; preserve required
attribution in an allowed location. Clearly identify original notices versus new
project information. Do not add terms purporting to change the license.

A project-specific inventory can record component, version, source URL, license,
original copyright and notice location. Fill it only from inspected artifacts;
no fictional copyright holders or examples copied as real dependencies.

For generated/minified bundles, verify shipped legal notices survive the build.
If distribution facts are unknown, provide a preparation checklist and identify
what needs inspection rather than claiming compliance.

- [Apache 2.0 section 4](https://www.apache.org/licenses/LICENSE-2.0)
