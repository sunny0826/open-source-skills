# Other Materials and Licenses

Separate software, documentation, data, artwork and trademarks. One repository
may need different licenses for different materials; identify file boundaries.

Creative Commons licenses are commonly used for creative content, not a default
software licensing choice. Check version, attribution, share-alike, noncommercial
and no-derivatives conditions before describing a work as open source. Source
availability alone does not meet an open-source definition.

For Boost, zlib, CC0, Unlicense or a less common license, read its canonical text
and relevant official guidance. Do not infer patent grants or jurisdictional
public-domain effects from the license name. Compare actual clauses and explain
uncertainty. Preserve terms on third-party components.

- [Creative Commons software guidance](https://creativecommons.org/faq/#can-i-apply-a-creative-commons-license-to-software)
- [OSI licenses](https://opensource.org/licenses)
